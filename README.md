## 🔬 Project Spotlight: Campunex

**The problem:** Campus and commuter ride-sharing usually runs through informal, unverified channels — group chats, notice boards, word of mouth — which leaves riders with no real way to confirm who they're actually getting into a car with.

**The concept:** Campunex is designed as a peer-to-peer ride-matching system scoped to a verified population (e.g. a campus or commuter community), so that ride requests and matches happen within a trusted, institutionally-verified circle rather than the open public.

**Core design pillars (architecture, not a feature changelog):**

- **Institutional verification** — matching is meant to be scoped to verified members of a campus/commuter community rather than anonymous public users.
- **Route & geospatial matching** — pairing riders based on overlapping routes rather than exact origin/destination matches.
- **Real-time trip/location functionality** — live trip state intended to give both rider and driver visibility during an active ride.
- **Secure ride-start verification** — a check intended to confirm the right rider is getting into the right vehicle before a trip begins.

> ⚠️ **Honesty note:** I don't have access to Campunex's source repository, so I can't confirm which of the above is fully implemented today versus still on the architecture/roadmap. This section describes the system's design intent as described by its creator, not a verified feature list. If/when the repo is public, I'd recommend replacing this note with links to the actual code and a demo.
